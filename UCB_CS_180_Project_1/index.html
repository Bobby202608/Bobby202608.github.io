01 / Overview

Three exposures, one color photograph

Sergei Prokudin-Gorskii recorded scenes through blue, green, and red filters on a single glass plate. The scans preserve these exposures as three vertically stacked grayscale images, but small shifts between them create strong color fringes when they are combined directly.

My pipeline splits each scan in B, G, R order, treats blue as the fixed reference, estimates translations for green and red, and merges the aligned channels into a color image. Small JPEGs use exhaustive single-scale search; full-resolution TIFFs use a coarse-to-fine image pyramid.

From glass plate to RGB

  3. 03 Align Estimate G→B and R→B translations with normalized L2 error.
  4. 04 Compose Shift the channels, clear invalid pixels, and merge the result.

02 / Single-scale alignment

Exhaustive search for small images

For each candidate displacement in a 31 × 31 search window, I shift the moving channel and compare only the valid overlap against the blue reference. The displacement with the smallest L2 score is retained.

Five percent of each edge is excluded before scoring so that the scanned plate border does not dominate the match. Pixel work is vectorized, while the displacement search remains an explicit pair of loops.

03 / Multi-scale alignment

Coarse estimates, fine corrections

Searching a large displacement window at full TIFF resolution is expensive. I recursively downsample both channels, solve the alignment at the coarsest level, then propagate the estimate back toward the original image.

At every finer level, the previous offset is scaled to the new dimensions and refined within a ±2 pixel neighborhood. The same L2 matcher is reused at every level, so the pyramid changes the search strategy rather than the matching objective.

06 / Analysis

What works, and where raw pixels struggle

Stable across scale

The pyramid recovers offsets as large as 178 pixels while keeping TIFF runtimes near four seconds. Coarse levels capture the large translation; full-resolution levels contribute only small corrections.

The Emir case

Emir is the hardest result for raw-pixel L2. The robe has very different intensities under the three filters, so equal spatial content does not imply equal pixel values. Edge or gradient features would reduce this color-dependent mismatch.

Border artifacts

Ignoring borders during scoring prevents the frame from steering the alignment, but the final composites still reveal colored plate edges. Automatic border detection and cropping would be a useful extension.

Fixed parameters

One search window, border fraction, pyramid depth, and refinement radius are used for all images. This makes the results reproducible and tests the algorithm rather than image-specific parameter tuning.

Implementation note

Built from basic operations

The implementation uses OpenCV for image I/O and resizing, and NumPy for array operations. Channel splitting, overlap-aware L2 scoring, exhaustive search, displacement propagation, and pyramid recursion are implemented in the project code without high-level alignment or pyramid functions.

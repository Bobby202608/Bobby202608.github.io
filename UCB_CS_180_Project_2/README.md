# CS 180 Project 2 Web Report

This directory contains a synchronized static scaffold for the Project 2 report. Open
`index.html` directly, or serve the project root with any static-file server:

```bash
cd ..
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The page uses an experimental workbench layout while leaving clearly labeled result
slots for all required non-Bells-and-Whistles tasks. Provided images are referenced from
`../input/`, so no asset copy is needed. Replace pending slots with experiment figures
and observations as the implementation is completed.

Part 1.1

Convolutions from Scratch

Here are the NumPy implementations of convolution with 4 and 2 for-loops respectively:

submission/code/part1.py

# a. Convolution with 4 for-loops:
def convolve_4_loops(img: np.ndarray, kernel: np.ndarray) -> np.ndarray:
    k_height, k_width = kernel.shape

    # Flip the kernel
    kernel_flip = np.flip(kernel, axis=(0, 1))

    # Change to the original size
    result = np.zeros((img.shape[0] - k_height + 1, img.shape[1] - k_width + 1), dtype=np.float64)

    for row in range(result.shape[0]):
        for col in range(result.shape[1]):
            for i in range(k_height):
                for j in range(k_width):
                    result[row, col] += img[row + i, col + j] * kernel_flip[i, j]

    return result


# b. Convolution with 2 for-loops:
def convolve_2_loops(img: np.ndarray, kernel: np.ndarray) -> np.ndarray:
    k_height, k_width = kernel.shape

    # Flip the kernel
    kernel_flip = np.flip(kernel, axis=(0, 1))

    # Change to the original size
    result = np.zeros((img.shape[0] - k_height + 1, img.shape[1] - k_width + 1), dtype=np.float64)

    for row in range(result.shape[0]):
        for col in range(result.shape[1]):
            window = img[row:row + k_height, col:col + k_width]
            result[row, col] = np.sum(window * kernel_flip)

    return result

Findings:

(1) Comparing between the two methods, the results are the same because of the associative property of convolution:
a * b * c = a * (b * c), where a is image matrix, b is Gaussian kernel, and c is Difference Operator, b * c is Derivative of Gaussian.

(2) Compared with Part 1.2, the results in Part 1.3 is less noisy, especially for the grassland and sky. With the help of Gaussian (low-pass) Filter, those salt-and-pepper noises are suppressed, while the cameraman and tripod's borders are extracted more clearly and correctly. However, the smoothing may lead to a loss of details, so decreasing the threshold in this case may be necessary to maintain the effect.

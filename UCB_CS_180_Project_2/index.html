Convolutions from Scratch

Here are the NumPy implementations of convolution with 4 and 2 for-loops respectively:

submission/code/part1.py

# a. Convolution with 4 for-loops:
def convolve_4_loops(img: np.ndarray, kernel: np.ndarray) -> np.ndarray:
    k_height, k_width = kernel.shape

    # Flip the kernel
    kernel_flip = np.flip(kernel, axis=(0, 1))

    # Change to the original size
    result = np.zeros((img.shape[0] - k_height + 1, img.shape[1] - k_width + 1), dtype=np.float64)

    for row in range(result.shape[0]):
        for col in range(result.shape[1]):
            for i in range(k_height):
                for j in range(k_width):
                    result[row, col] += img[row + i, col + j] * kernel_flip[i, j]

    return result


# b. Convolution with 2 for-loops:
def convolve_2_loops(img: np.ndarray, kernel: np.ndarray) -> np.ndarray:
    k_height, k_width = kernel.shape

    # Flip the kernel
    kernel_flip = np.flip(kernel, axis=(0, 1))

    # Change to the original size
    result = np.zeros((img.shape[0] - k_height + 1, img.shape[1] - k_width + 1), dtype=np.float64)

    for row in range(result.shape[0]):
        for col in range(result.shape[1]):
            window = img[row:row + k_height, col:col + k_width]
            result[row, col] = np.sum(window * kernel_flip)

    return result

Part 2.3 & 2.4

Gaussian and Laplacian Stacks, Multiresolution Blending

A Gaussian Stack G as well as a Laplacian Stack L are constructed for each component image. A Gaussian Stack M is also constructed for the mask.

There are 6 levels in each stack, from level 0 to level 5. The standard deviation (σ) of level k is 2^k, representing the width transition between the two components, the bigger the wider.

For the components,
◇ Between each level of G, we have: G_0 = I, G_1 = G_0 * G(σ), G_2 = G_1 * G(2σ), ...
◇ Between each level of L, we have: L_5 = G_5, L_4 = G_4 - G_5, L_3 = G_3 - G_4, ...

After implementing mask on each component and summing them up, we get a Laplacian Stack L' for the blended image.
At level k of L', we have: L'_k = M_k * L_{A_k} + (1 - M_k) * L_{B_k}

Since I = G_0 = (G_0 - G_1) + (G_1 - G_2) + ... + G_5 = L_0 + L_1 + ... + L_5,
◇ By summing up all levels of M * L_A, we can get the masked left component;
◇ By summing up all levels of (1 - M) * L_B, we can get the masked right component;
◇ By summing up all levels of L', we can get the final blended image.
